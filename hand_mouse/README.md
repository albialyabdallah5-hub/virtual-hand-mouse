# Virtual Hand Mouse

A real-time virtual mouse built with **Python**, **OpenCV**, **MediaPipe Hand Landmarker**, and **PyAutoGUI**, using a camera feed (such as iVCam).

## Controls
- **Move Cursor:** Index finger movement inside the tracking box.
- **Left Click:** Lift/extend the thumb clearly.
- **Right Click:** Extend the pinky finger clearly.
- **Quit:** Press `Q` in the video window.

## Requirements
- `opencv-python`
- `mediapipe`
- `numpy`
- `pyautogui`
- `hand_landmarker.task` placed in the project folder.
